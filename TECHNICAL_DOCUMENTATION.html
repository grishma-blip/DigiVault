1. Executive Pitch: Problem & Built Solution Project Vision
🛑 The Problem
Carrying physical documents like Aadhaar, PAN card, Driving License, or college marksheets everywhere is risky. They can easily get lost, damaged, or stolen. On the other hand, simple phone screenshots or photos are often not accepted as official proof.
💡 The Solution (What I Built)
To solve this, I built a secure Flutter app (DigiVault) where users can safely store, view, and share their official digital documents in one place, complete with QR code verification, 2048-bit PKI cryptographic signatures, and PIN security.

4. Parameter 2: Dart Fundamentals & Package Ecosystem 5 / 5 Marks
  • Architecture & State Management: Follows Clean Architecture with Feature-First structure. Presentation and Business Logic are decoupled using production-standard Provider (ChangeNotifier):
    • AuthProvider: Controls User Login, OTP, PIN, and App Lock state.
    • DocumentProvider: Manages Document Library, Filter Tabs, and Issuance tracking.
    • ShareProvider: Generates time-bound password-protected sharing links.
    • ThemeProvider: Notifies app UI on Light/Dark theme changes.
  • Async Data Flow & Sound Null Safety: Local I/O, SHA-256 crypto hashing, and JSON serialization run asynchronously using Future and async/await. Codebase enforces 100% Sound Null Safety to guarantee zero runtime NullPointerExceptions.
