1. Executive Pitch: Problem & Built Solution Project Vision
🛑 The Problem
Carrying physical documents like Aadhaar, PAN card, Driving License, or college marksheets everywhere is risky. They can easily get lost, damaged, or stolen. On the other hand, simple phone screenshots or photos are often not accepted as official proof.
💡 The Solution (What I Built)
To solve this, I built a secure Flutter app (DigiVault) where users can safely store, view, and share their official digital documents in one place, complete with QR code verification, 2048-bit PKI cryptographic signatures, and PIN security.

A. Architecture & State Management (`Provider` Pattern):
App Clean Architecture with Feature-First structure follow karta hai. Business logic aur presentation layer bilkul decoupled hain using industry-standard Provider (ChangeNotifier):

lib/features/auth/providers/auth_provider.dart AuthProvider (User Login, OTP, PIN & Lock)
class AuthProvider extends ChangeNotifier { UserModel _user = StorageService.getUser(); AuthState _authState = StorageService.isLoggedIn() ? AuthState.authenticated : AuthState.unauthenticated; Future<bool> verifyOtp(String enteredOtp) async { _isLoading = true; notifyListeners(); await Future.delayed(const Duration(milliseconds: 500)); _authState = AuthState.authenticated; await StorageService.setLoggedIn(true); notifyListeners(); return true; } }
lib/features/documents/providers/document_provider.dart DocumentProvider (Library, Category Filter & Search)
class DocumentProvider extends ChangeNotifier { List<DocumentModel> _documents = StorageService.getDocuments(); String _selectedCategory = 'All'; List<DocumentModel> get documents { if (_selectedCategory != 'All') { return _documents.where((doc) => doc.category == _selectedCategory).toList(); } return _documents; } }
lib/features/secure_sharing/providers/share_provider.dart ShareProvider (Time-Bound PIN Secure Links)
class ShareProvider extends ChangeNotifier { Future<ShareModel> createShare({required DocumentModel document, required int durationHours, required String accessPin}) async { final expiresAt = DateTime.now().add(Duration(hours: durationHours)); final share = ShareModel(documentId: document.id, expiresAt: expiresAt, accessPin: accessPin); _shares.insert(0, share); notifyListeners(); return share; } }

class ThemeProvider extends ChangeNotifier { ThemeMode _themeMode = ThemeMode.light; Future<void> toggleTheme(bool isDark) async { _themeMode = isDark ? ThemeMode.dark : ThemeMode.light; await StorageService.setString('app_theme_mode', isDark ? 'dark' : 'light'); notifyListeners(); } }
